A compact chess engine in 4 KB of Python: alpha-beta search with null-move pruning, late-move reductions, check extensions, quiescence, a transposition table, MVV-LVA ordering, and real piece-square tables, built to play the make.fun tiny-chess-01 gauntlet.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
